# 实验冻结协议

1. 在调用任何模型前冻结 `k12simbench.jsonl`、prompt 版本和 JSON Schema 校验和。
2. 完整 240 题每个模型—方法组合运行一次；专家 60 题使用三个独立重复。
3. 保留原始响应、解析后产物、一次修复响应、渲染日志和 manifest。
4. 所有引擎使用固定画布、帧率、时长上限、时间步和摄像机约束。
5. 主结果包含失败样本零分；同时报告执行成功率和一次修复率。
6. 按模型、方法、学科、年级、题型、知识点和模拟类型汇总。
7. 配对比较使用 10,000 次 bootstrap 置信区间与配对随机化检验，多重比较用 Holm 校正。
8. 只有解题质量、关键事件和教师评分同步提升时，才使用“改善教育推理”；仅视觉指标提高时使用“改善表现形式”。

## 消融矩阵

| 方法 | WorldSpec | 状态锚定 | 物理原生引擎 | 动态输出 |
|---|---:|---:|---:|---:|
| text_cot | 否 | 否 | 否 | 否 |
| static_manim | 否 | 第一图视觉锚定 | 否 | 否 |
| direct_code | 否 | 否 | 可选 | 是 |
| unanchored | 是 | 否 | 是 | 是 |
| k12simworld_state_anchored | 是 | 是 | 按路由 | 是 |
| k12simworld_candidate_target | 是 | 候选解答初态/终态/事件 | 按路由 | 是 |

candidate_target 中的目标来自被测模型自己的无答案解题结果，用于评价仿真内部一致性；
标准答案和专家轨迹只在生成完成后用于独立评价。具体命令见 CANDIDATE_TARGET_EVALUATION_CN.md。

模型和 API 版本、价格、运行日期必须原样写入实验元数据，避免把预览模型名当作稳定接口。
